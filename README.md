# Validación de un programa multicomponente para la prevención de caídas en personas mayores

## 📖 Descripción del Proyecto

Este proyecto aplica el **Sistema de Especificación del Tratamiento de Rehabilitación** (*Rehabilitation Treatment Specification System*, **RTSS**) como marco metodológico para el diseño y estructuración de intervenciones para la prevención de caídas.

El RTSS aporta precisión terminológica y rigor a los procedimientos de rehabilitación mediante la descomposición de cualquier intervención en una **tríada causal**:

1. **Ingredientes:** Acciones observables, materiales y dosis seleccionadas por el terapeuta.
2. **Mecanismos de Acción:** Procesos biológicos o psicológicos activados directamente por los ingredientes.
3. **Objetivos:** Cambios funcionales específicos que se buscan alcanzar en el paciente.

---

## 🎯 Enfoque Clínico: Prevención de Caídas en Adultos Mayores

A través de la metodología RTSS, la prevención de caídas pasa de ser un conjunto de recomendaciones generales a una **prescripción técnica de alta precisión**. 

* **Fin Último:** Preservar la capacidad funcional y autonomía del individuo, reduciendo la fragilidad.
* **Impacto:** Permite al adulto mayor interactuar con su entorno de manera segura, promoviendo una longevidad activa, independiente y saludable.
